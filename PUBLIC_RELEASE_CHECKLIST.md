# Public Release Checklist

Use this checklist before pushing a public AdMesh SDK release.

- No secrets or production SDK keys are committed.
- No local file paths, localhost URLs, or temporary worker URLs appear in public docs.
- README is complete and uses public-facing SDK language.
- LICENSE is present and matches the intended public license strategy.
- PRIVACY.md and TERMS.md point to the current AdMesh canonical pages.
- THIRD_PARTY_NOTICES.md reflects intentionally shipped material.
- CHANGELOG.md is updated for the release version.
- Plugin/package version matches the intended release version.
- Public endpoints and example configuration use approved AdMesh URLs.
- Sample content still runs with fallback/test mode.
- Git identity and commit message format are correct for release work.
- Remaining manual/legal review items are explicitly listed before push.
